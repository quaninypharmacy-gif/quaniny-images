# quaniny-images

صور أصناف صيدلية كوانيني اللي بتظهر على quaniny.com — **النسخة النهائية بالقالب بس**.

- `p/<رقم الصنف>-400.webp` للكروت، و`p/<رقم الصنف>-1000.webp` لصفحة الصنف.
- الصورة الأصلية (من غير القالب) **مش هنا** — محفوظة عند الصيدلية على PC1 عشان لو القالب اتغير تتعمل كل الصور تاني منها.
- الصور بتتعمل بـ `tools/product-images/render-template.js` في سيستم Quaniny، وبتتراجع بالعين قبل ما تترفع.
- قايمة الأصناف اللي ليها صورة في ريبو الموقع: `data/images.json`.

مفيش في الريبو ده أي بيانات مرضى ولا أسرار.
